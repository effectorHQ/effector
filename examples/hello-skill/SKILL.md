# hello-skill

Process the input text and return the result.

## Purpose

A minimal example skill that takes a string and returns a string. Demonstrates the simplest possible effector.toml manifest.

## When to Use

Use this as a starting template or reference for building typed agent tools with effector.

## Setup

No setup required. This skill has no permissions and no external dependencies.

## Examples

```bash
effector check .              # validate the manifest
effector compile . -t mcp     # compile to MCP tool schema
effector inspect .            # view the interface
```
